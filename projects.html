Backend Systems / Financial Technology / Operational Visibility

File Tracking Pipeline

Overview

At Fiserv, I worked with a 6-person engineering team on a high-throughput file tracking pipeline designed to monitor document movement across distributed financial systems. The system helps teams understand where files are, what status they are in, whether failures occurred, and whether reconciliation issues need investigation.

Problem

File movement across multiple systems can become difficult to trace when events are spread across logs, databases, and operational tools. Missing files, duplicates, orphaned records, and failed processing events create investigation overhead for support and engineering teams.

My Role

  • Designed and implemented backend API workflows using Java and Spring Boot.
  • Built REST endpoints for file status lookup and event tracking.
  • Worked with Kafka-based event flow concepts for ingesting file activity.
  • Supported audit logging for ingestion, duplicate detection, failure events, orphaned files, and reconciliation history.
  • Worked in Agile development cycles with sprint planning, standups, reviews, and iterative delivery.

Technical Breakdown

  • Java Spring Boot backend services and REST APIs.
  • Kafka for event-driven file activity ingestion.
  • Oracle schemas and indexes for structured persistence.
  • Redis-backed lookup patterns for faster file status searches.
  • Postman, GitLab, and Docker for testing and development workflow.

Impact

Improved the ability to search and understand file status across distributed workflows. Helped reduce manual investigation by giving teams a centralized way to inspect file activity, processing history, and operational exceptions.

Fleet Operations / Computer Vision Workflow / Logistics

Drone-Based Truck Inspection Platform

Overview

Designed with AY Logistics, this platform helps trucking operations teams capture inspection evidence, review vehicle issues, and track maintenance follow-ups from a web dashboard. The goal is to move truck inspection workflows away from scattered manual notes and toward a centralized operational system.

Problem

Trucking companies need better visibility into truck condition, inspection history, unresolved vehicle issues, and maintenance follow-up status. Without a centralized platform, evidence can be hard to review, issues can be missed, and maintenance tracking becomes inconsistent.

My Role

  • Helped define the product workflow with AY Logistics.
  • Designed dashboard flows for fleet inspection status.
  • Built reusable React UI components for cards, forms, status views, and review screens.
  • Collaborated on backend API design for image ingestion, issue tagging, damage evidence storage, and maintenance follow-up tracking.

Technical Breakdown

  • React frontend dashboard for operational review workflows.
  • Python and FastAPI backend API planning.
  • Image ingestion, issue tagging, and damage evidence storage workflows.
  • Vehicle inspection history and maintenance follow-up tracking.

Impact

Created a clearer workflow for fleet inspection review, maintenance visibility, and operational follow-up. The platform is designed to help operations teams manage inspection evidence and vehicle issues from one place.

AI / Product Strategy / Social Impact

GrantPilot AI Grant Success Platform

Overview

GrantPilot is an AI-driven platform designed to connect underserved founders with relevant grant opportunities. The platform uses AI matching and pipeline tracking to make funding discovery easier and more organized.

Problem

Founders often struggle to find grants that match their business type, stage, location, and eligibility requirements. The process is fragmented, time-consuming, and difficult to track.

My Role

  • Developed the AI-driven matching engine concept using Retrieval-Augmented Generation.
  • Helped design opportunity matching and pipeline tracking workflows.
  • Worked on product strategy for a B2B2C model targeting local government and CDFI sectors.
  • Contributed to a project that won 1st place among 20+ teams at the MLT Tech Trek Ideathon.

Technical Breakdown

  • Retrieval-Augmented Generation and AI-driven opportunity matching.
  • Founder profile matching and grant pipeline tracking workflows.
  • B2B2C product strategy for local government and CDFI use cases.

Impact

Won 1st place among 20+ teams at the MLT Tech Trek Ideathon and demonstrated how AI can help founders discover and organize funding opportunities more effectively.
